# Linux Port: Shell Script and FFmpeg Path Configuration

## Objective
Convert the Windows batch file to a Linux shell script and configure the application to use the local FFmpeg installation at `/home/akira/Downloads/ffmpeg-n8.1-latest-linux64-gpl-8.1/`.

## Analysis
- **Current launcher**: `Run_PySide6.bat` changes to `PySide6` directory and runs `python main.py`
- **FFmpeg detection**: Application supports custom FFmpeg path via settings, auto-detection, or system PATH
- **Configuration**: Settings stored in `PySide6/settings.json`; defaults in `PySide6/config.py`
- **FFprobe**: Also required and used alongside FFmpeg
- **Verified**: FFmpeg package exists at specified path with `bin/ffmpeg` and `bin/ffprobe` executables

## Implementation Steps

### 1. Create Shell Script `Run_PySide6.sh`
```bash
#!/bin/bash
# Video Encoder - PySide6 Launcher (Linux)
# Change to PySide6 directory and run the application

cd "$(dirname "$0")/PySide6" || exit 1

# Prefer python3, fallback to python
if command -v python3 &>/dev/null; then
    python3 main.py
elif command -v python &>/dev/null; then
    python main.py
else
    echo "Error: Python not found. Please install Python 3."
    read -p "Press Enter to continue..."
    exit 1
fi
```

### 2. Make Script Executable
```bash
chmod +x Run_PySide6.sh
```

### 3. Update `PySide6/settings.json`
Replace the default `ffmpeg_path` with the full Linux path to the FFmpeg binary:
```json
{
  "ffmpeg_path": "/home/akira/Downloads/ffmpeg-n8.1-latest-linux64-gpl-8.1/bin/ffmpeg",
  "output_folder": "C:/Users/Admin/Desktop"
}
```
*Note: The output_folder path remains Windows-style for now; it will be adjusted on first run.*

### 4. Update `PySide6/config.py` Constants (Optional but Recommended)
Change the Windows paths to Linux paths for consistency and documentation:
```python
FFMPEG = r"/home/akira/Downloads/ffmpeg-n8.1-latest-linux64-gpl-8.1/bin/ffmpeg"
FFPROBE = r"/home/akira/Downloads/ffmpeg-n8.1-latest-linux64-gpl-8.1/bin/ffprobe"
```
*Note: These constants are currently unused in the codebase but good to maintain.*

## Additional Considerations
- The application uses Qt (PySide6) which is cross-platform; no other code changes needed
- The script uses `$(dirname "$0")` to handle paths correctly regardless of working directory
- Error handling includes checking for Python availability and pausing on failure (via `read`)
- `ffprobe` path is automatically deduced from `ffmpeg_path` in most code paths (same directory logic)
